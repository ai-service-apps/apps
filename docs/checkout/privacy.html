Информация об обработке персональных данных

Информация об условиях будущей услуги · актуализировано 14 октября 2026 г.

Сервис готовится к запуску. Сейчас платежи не принимаются, заказы с оплатой не оформляются. Разделы описывают планируемый порядок работы и будут уточнены до запуска.

1. Для чего используется сайт

Apple Inside Apps показывает каталог и стоимость услуг, а в дальнейшем может обеспечивать оформление и сопровождение заказов. Сейчас на странице нет регистрационной формы и оплата отключена.

2. Какие сведения могут обрабатываться

При посещении сайта и обращениях в поддержку могут обрабатываться технические сведения о запросах к сайту и API (например, IP-адрес, браузер, дата запроса), а также данные, которые пользователь добровольно предоставляет при обращении, например номер заказа и контактный телефон.

После подключения оплаты отдельные необходимые сведения о транзакции (сумма, идентификатор и статус платежа) будут передаваться между платёжным оператором и сервером заказов. Полные данные банковской карты сайт не должен получать и хранить.

3. Цели и меры защиты

Цели обработки: работа каталога, диагностика технических ошибок, обработка запросов, сопровождение заказов и обеспечение безопасности. Передача данных сторонним сервисам допускается в рамках их роли по техническому обслуживанию сайта и обработке платежей и при наличии законного основания.

Для размещения интерфейса используются GitHub Pages, для API и данных заказов — Supabase. У этих провайдеров есть собственные условия обработки данных. Не публикуйте в открытых формах пароли, полные данные карт и коды Apple Account.

4. Обращения по данным

Для вопросов об использовании и удалении персональных данных обратитесь к Apple Inside Service по номеру +7 938 432-22-02. Перед запуском коммерческого приёма заказов эта страница будет дополнена утверждёнными реквизитами оператора, сведениями о сроках хранения и основаниях обработки.
