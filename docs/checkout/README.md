# Apple Inside Apps — отдельная страница продажи

Предпросмотр: https://ai-service-apps.github.io/apps/docs/checkout/

Это **внешняя страница**, не вызываемая из Telegram Mini App. Она показывает цены из отдельной базы Supabase `Apple Inside Apps`. Оплата сознательно выключена.

## Для запуска независимой продажи через браузер

1. Подтвердить права на распространение каждого IPA, проверить подпись, установку и активацию.
2. Выбрать эквайринг: например, ЮKassa или Т-Банк, подключить СБП и карты, проверить ИП и требования онлайн-кассы.
3. Создать защищённый серверный маршрут для платёжной ссылки (цена только из базы) и обработчик webhook со сверкой платежа через API провайдера.
4. Выпускать временный установочный доступ только после `succeeded`; обеспечить возврат и поддержку.
5. Настроить собственный домен для независимого сайта, если потребуется.
6. Не использовать Telegram Mini App для обхода требования Telegram Stars при продаже цифровых услуг внутри Telegram: https://core.telegram.org/bots/payments-stars

Секреты платежного провайдера запрещено хранить на GitHub Pages; сервер должен использовать Supabase Edge Functions secrets. Отдельный сайт сейчас не является действующим пунктом приема платежей.
