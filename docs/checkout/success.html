Проверяем поступление платежа

Перенаправление после платежа само по себе не подтверждает оплату. Когда платёжный сервис будет подключён, информация о платеже будет проверяться на сервере. Установочные ссылки не выдаются только на основании посещения этой страницы.

Если оплата уже была произведена, но заказ не обновился, обратитесь по телефону +7 938 432-22-02 с номером заказа.
