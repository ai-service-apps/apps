# Apple Inside Apps · Telegram Mini App

Рабочий интерфейс: `docs/index.html`
Сервер заказов: `supabase/functions/apps-orders/index.ts`
Проект Supabase: `cmcfwkfhyxfljpowbkpj`, отдельно от AI Service LiveSklad.

## Что сделано
- каталог с категориями, поиском и выбором нескольких приложений;
- загрузка каталога из базы Supabase;
- отправка заявки из Mini App в отдельную базу;
- серверная проверка Telegram WebApp initData (HMAC-SHA256);
- сохранение состава заявки; ограничение количества запросов и повторов;
- раздел «Мои заявки» с реальными заказами;
- уведомление клиенту в Telegram и необязательное уведомление администратору;
- инструкция, контакты сервиса;
- действующие старые URL инсталляции в репозитории не изменены.

## Что нужно доделать для полноценной работы
1. Supabase → Edge Functions → Secrets: `TELEGRAM_BOT_TOKEN` (секрет из BotFather, никогда не в GitHub).
2. Необязательно: `TELEGRAM_ADMIN_CHAT_ID` для уведомлений администратору. Получатель должен сначала нажать Start в боте.
3. Открыть Mini App через @AppleInsideAppsBot, выбрать приложение, отправить тестовую заявку, проверить таблицы `app_orders` и `app_order_items`, «Мои заявки» и уведомление в Telegram.

Пока нет приёма оплаты, подтверждения фактической доступности приложений, выдачи ссылок и автоматической активации. По умолчанию все позиции — запрос на уточнение, а не готовые к оплате товары. Пароли Apple Account и коды 2FA бот не собирает.

## Публикация
GitHub Pages оставляем `main / (root)`; публичный адрес: `https://ai-service-apps.github.io/apps/docs/`.
Бот `@AppleInsideAppsBot` уже имеет настроенную кнопку меню.

Серверная функция использует `verify_jwt=false`, поскольку проверяет подписанные Telegram данные на сервере собственным механизмом. Таблицы защищены RLS, для прямых клиентских ролей `anon` и `authenticated` права отозваны. Перед открытием платных операций потребуется проверка оплаты на сервере, защита от гонок запросов и отдельный аудит безопасности.
