# Apple Inside Apps · Telegram Mini App (MVP)

Рабочая первая версия интерфейса находится в `docs/index.html`.

## Реализовано
- мобильный каталог с поиском, категориями и выбором приложений;
- оформление **локального черновика** заявки;
- история черновиков в localStorage данного устройства;
- передача текста черновика в сервис через WhatsApp или пересылка через Telegram;
- инструкции по установке и активации через «Контент и покупки»;
- адаптация под Telegram Mini Apps и отдельный браузер.

## Пока НЕ подключено
- Telegram Bot API и создание бота через @BotFather;
- серверное получение заявок, авторизация пользователей на сервере, единая база;
- реальные цены, наличие и установочные ссылки;
- оплата / Telegram Stars;
- выдача или хранение Apple Account, паролей и кодов.

**Внимание:** это тестовый интерфейс. Черновик не поступает в сервис автоматически, пока клиент не нажмёт «Отправить в сервис» или не отправит текст через Telegram. Не вводите реальные секреты и пароли в исходный код, HTML или публичный репозиторий.

## Как опубликовать
1. Откройте настройки репозитория: Settings → Pages.
2. В Source выберите Deploy from a branch.
3. Branch: `main`, Folder: `/docs`, Save.
4. После публикации проверьте адрес `https://ai-service-apps.github.io/apps/`.
5. Создайте отдельного бота в @BotFather. Через /setmenubutton задайте название кнопки («Открыть приложения») и **фактический опубликованный URL**.
6. Проверьте запуск, поиск, выбор, формирование и пересылку черновика на iPhone.

Текущая версия специально не содержит секретов, платёжной формы и не рассылает пароли/2FA-коды. Следующий этап: защищённый backend с серверной проверкой Telegram initData, каталогом, реальными заказами и контролируемым процессом активации.
